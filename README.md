#  NOVA – Smart Career & Skill Development Platform

NOVA is a modern and interactive career development platform designed to help individuals organize their career goals, assess their skills, track learning progress, and explore career opportunities.

Built as an independent project for the **TechWave Internship – First Task** using HTML, CSS, and Vanilla JavaScript.

##  Features

- **Interactive Dashboard:** Overview of career progress and development statistics.
- **Career Roadmap:** Create, manage, complete, and delete career milestones.
- **Skill Assessment:** Evaluate proficiency levels in HTML, CSS, JavaScript, Responsive Design, and Problem Solving.
- **Opportunities:** Explore career opportunities with search and filtering functionality.
- **Dark & Light Mode:** Switch between themes for a comfortable experience.
- **Local Storage:** Automatically preserve milestones, skill assessments, and theme preferences.
- **Responsive Design:** Optimized layout for desktop, tablet, and mobile devices.
- **Modern UI:** Clean interface with a professional purple-themed design.
